# 08. 마무리

실제 사용자의 반응을 받아 고치고, 프로젝트를 정리합니다.

## 1. 친구들에게 공유하기

공유하기 전에 질문을 10개 이상 넣어 두세요. 첫 화면이 비어 있으면 무엇을 하는 사이트인지 알기 어렵습니다.

5명 이상에게 링크를 보내고 다음을 관찰합니다.

- 설명 없이 가입과 투표까지 해내는가
- 어디서 멈추거나 헷갈려 하는가
- 직접 질문을 등록하는가
- 오류를 만난 사람이 있는가

"어때?"보다 "어디서 막혔어?"처럼 구체적으로 묻는 편이 쓸 만한 답을 얻습니다.

고칠 때는 재현 테스트를 먼저 작성합니다.

## 3. DB 백업

호스팅의 자동 백업 여부와 보관 기간을 확인합니다. 무료 플랜이라면 직접 백업하는 방법도 익혀 두세요.

```bash
pg_dump "$DATABASE_URL" -Fc -f balance_game.dump
```

백업은 복원해 봐야 쓸 수 있는지 알 수 있습니다. 로컬에 빈 DB를 만들어 복원해 봅니다.

```bash
createdb balance_game_restore
pg_restore --no-owner -d balance_game_restore balance_game.dump
```

`pg_dump` 버전이 운영 서버보다 낮으면 실패할 수 있습니다. 덤프 파일에는 사용자 정보가 들어 있으니 저장소에 올리지 마세요.

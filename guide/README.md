# balance-game 가이드북

[프로젝트 계획](../README.md)을 실제로 만들어 가는 챕터별 안내서입니다. 계획은 "무엇을 만들지"를, 이 가이드는 "어떤 순서로 어떻게 만들지"를 다룹니다.

## 챕터

| 챕터 | 가이드 | 끝나면 되는 것 |
|---|---|---|
| 00 | [프로젝트 준비](00-project-setup.md) | Next.js 화면에서 Django API 호출 |
| 01 | [회원가입과 로그인](01-auth.md) | 세션 로그인과 CSRF가 브라우저에서 동작 |
| 02 | [질문 등록과 조회](02-questions.md) | 질문 등록, 목록, 상세 |
| 03 | [투표와 결과](03-votes.md) | 1인 1표 투표와 득표율 확인 |
| 04 | [첫 배포](04-deploy.md) | 친구에게 보낼 수 있는 URL |
| 05 | [내 질문 관리와 권한](05-permissions.md) | 작성자만 수정·삭제 가능 |
| 06 | [댓글](06-comments.md) | 쿼리 수가 늘지 않는 댓글 API |
| 07 | [재미 요소](07-fun-features.md) | 정렬, 랜덤 질문, 공유 미리보기 |
| 08 | [마무리](08-wrap-up.md) | 사용자 피드백 반영과 회고 |

## 읽는 방법

1. 챕터를 시작하기 전에 전체를 한 번 읽습니다.
2. **설계 질문**에 먼저 답을 적습니다. 모델은 코드를 쓰기 전에 필드와 관계부터 정리합니다.
3. 단계 순서대로 만들되, 접힌 **힌트**는 막혔을 때만 엽니다.
4. **완료 확인**을 모두 통과한 뒤 커밋하고 [진도](../README.md#진도)에 표시합니다.
5. 막혔던 내용은 `notes/`에 정리합니다.

## 코드를 어디까지 제공하나

| 구분 | 가이드에서 제공하는 것 | 직접 하는 것 |
|---|---|---|
| 설치·설정 | 명령어와 설정 코드 | 값의 의미 이해하기 |
| 세션·CSRF 연결 | 동작이 확인된 핵심 코드 | 로그인, 회원가입 로직 |
| 모델·Serializer·View | 설계 질문, API 명세, 힌트 | 설계와 구현 전부 |
| Next.js 화면 | 백엔드 연동에 필요한 조건 | 화면 구성과 상태 관리 |

## 버전 기준

2026년 11월 6일에 아래 버전으로 설치부터 세션 로그인까지 실행해 확인했습니다. 호스팅 서비스에 올리는 단계는 서비스마다 달라서 포함하지 않았습니다.

| 도구 | 버전 |
|---|---|
| Python | 3.11 |
| Django | 5.2 |
| Django REST Framework | 3.18 |
| PostgreSQL | 17 |
| Next.js | 16.4 |
| React | 19.3 |
| Node.js | 26.7 |

새 버전을 쓴다면 설치 명령의 기본 옵션과 설정 파일이 다를 수 있으니 공식 문서를 함께 확인하세요.

## 전 챕터 공통 규칙

- 권한과 공개 범위는 화면이 아니라 API에서 보장합니다.
- API 주소는 `/api/questions/1`처럼 끝 슬래시 없이 씁니다.
- 기능을 끝낼 때 테스트도 함께 작성합니다.
- 커밋은 [커밋 규칙](../README.md#커밋-규칙)을 따릅니다.
